# Быстрый старт — Демо для хакатона

## 🚀 Запуск за 2 минуты

### 1. Установка зависимостей

```bash
cd korsik-bot
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Создание .env файла

```bash
copy .env.example .env
```

**Важно:** Для демо оставьте `DEMO_MODE=true`. Бот будет работать без ключей MAX и GigaChat.

### 3. Запуск сервера

```bash
cd backend
uvicorn app.main:app --reload
```

Сервер запустится на `http://127.0.0.1:8000`

## 💬 Тестирование бота

### Вариант 1: Веб-интерфейс MAX (рекомендуется для демо)

Откройте браузер и перейдите:
```
http://127.0.0.1:8000/demo/max/chat
```

Это интерактивный чат, имитирующий интерфейс MAX мессенджера.

**Что попробовать:**
- `/start` — начать регистрацию
- `Какой рабочий график?` — вопрос из базы знаний
- `Где моя зарплата?` — вопрос вне базы знаний (эскалация в HR)
- `/help` — справка
- `/status` — показать маршрут адаптации

### Вариант 2: Основной дашборд

```
http://127.0.0.1:8000
```

Нажмите «Загрузить демо-данные», затем переключайте роли:
- 👤 Новый сотрудник
- 👔 HR-менеджер
- 📊 Руководитель подразделения
- 📈 Руководитель по подбору и развитию

### Вариант 3: API напрямую

Откройте Swagger документацию:
```
http://127.0.0.1:8000/docs
```

Или через curl:

```bash
curl -X POST "http://127.0.0.1:8000/api/chat" \
  -H "Content-Type: application/json" \
  -d "{\"user_id\": \"test_123\", \"text\": \"/start\"}"
```

## 🧪 Тестирование MAX webhook

### Эмуляция входящего сообщения от MAX

```bash
curl -X POST "http://127.0.0.1:8000/demo/max/webhook/test" \
  -H "Content-Type: application/json" \
  -d '{
    "message": {
      "sender": {
        "user_id": "user_12345",
        "name": "Алексей"
      },
      "recipient": {
        "chat_id": "chat_67890"
      },
      "body": {
        "text": "Какой рабочий график?"
      }
    }
  }'
```

Ответ покажет:
- Распознанное сообщение
- Ответ бота
- Источники из базы знаний

## 📋 Сценарий демонстрации для жюри

### 1. Показать чат нового сотрудника (5 мин)

Откройте `/demo/max/chat` и продемонстрируйте:

1. **Регистрация:**
   ```
   /start
   → инженер-технолог
   → есть опыт
   → GrPP
   → 03.11.2026
   → получать
   ```

2. **Вопрос с ответом из базы знаний:**
   ```
   Какой рабочий график?
   ```
   → Корсик находит ответ в документе "Правила внутреннего трудового распорядка"

3. **Вопрос вне базы знаний:**
   ```
   Где получить пропуск?
   ```
   → Корсик честно отказывается угадывать и предлагает эскалацию в HR

### 2. Показать HR-дашборд (3 мин)

Откройте `http://127.0.0.1:8000` → роль "HR-менеджер":
- Видны открытые обращения
- Агрегированные темы вопросов
- Статистика по адаптации

### 3. Показать руководителю подразделения (2 мин)

Роль "Руководитель подразделения":
- Этапы адаптации команды
- **Без содержания личной переписки** — только статусы

### 4. Показать сводку для топ-менеджмента (2 мин)

Роль "Руководитель по подбору и развитию":
- Weekly digest по настроению
- Зоны внимания
- **Без персональных данных**

## 🔧 Что делать, если что-то не работает

### Ошибка: "ModuleNotFoundError"

```bash
pip install -r requirements.txt
```

### Ошибка: "Database not found"

Сервер создаёт БД автоматически при первом запуске. Убедитесь, что:
```bash
cd backend
uvicorn app.main:app --reload
```

### Порт 8000 занят

Запустите на другом порту:
```bash
uvicorn app.main:app --reload --port 8001
```

## 📦 Подготовка к реальному MAX

После получения токена бота от кабинета MAX:

### 1. Отредактируйте `.env`:

```env
DEMO_MODE=false
MAX_BOT_TOKEN=ваш_токен_бота
MAX_SEND_MESSAGE_URL=https://api.max.ru/v1/messages/send
MAX_RECIPIENT_LOCATION=body
MAX_RECIPIENT_FIELD=chat_id
MAX_WEBHOOK_SECRET=ваш_webhook_секрет
```

### 2. Развёртывание с публичным HTTPS

Для webhook MAX нужен публичный адрес. Варианты:

**Вариант A: ngrok (для теста)**

```bash
ngrok http 8000
```

Скопируйте HTTPS URL и зарегистрируйте webhook в кабинете MAX:
```
https://ваш-ngrok.ngrok.io/webhooks/max
```

**Вариант B: Реальный сервер**

Разверните на сервере с SSL сертификатом и укажите webhook:
```
https://ваш-домен.ru/webhooks/max
```

### 3. Тест round-trip

Напишите боту в MAX:
```
Какой рабочий график?
```

Должен прийти ответ со ссылкой на источник.
