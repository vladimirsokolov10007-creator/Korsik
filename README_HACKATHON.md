# 🤖 Корсик 2.0 — Чат-бот для адаптации сотрудников

> MAX мессенджер + RAG + GigaChat = Безопасный AI-наставник на хакатон

## 🎯 Что это?

**Корсик** — это рабочий MVP для хакатона, который помогает новым сотрудникам адаптироваться в компании. Бот работает в MAX мессенджере, отвечает только по проверенным документам и передаёт сложные вопросы HR.

### ✨ Ключевые особенности

- ✅ **Безопасный RAG**: отвечает только по утверждённым документам
- ✅ **MAX интеграция**: готов к подключению реального бота
- ✅ **4 роли**: сотрудник, HR, руководитель, топ-менеджмент
- ✅ **Демо-режим**: работает без ключей API для презентации
- ✅ **Эскалация в HR**: честно признаёт, когда не знает ответа
- ✅ **GigaChat опционально**: демо работает на чистом RAG

## 🔧 Конфигурация для реального MAX

После получения токена бота:

### 1. Отредактируйте `.env`:

```env
DEMO_MODE=false
MAX_BOT_TOKEN=ваш_токен_из_кабинета_MAX
MAX_SEND_MESSAGE_URL=https://api.max.ru/v1/messages/send
MAX_RECIPIENT_LOCATION=body
MAX_RECIPIENT_FIELD=chat_id
MAX_WEBHOOK_SECRET=секрет_для_webhook
```

### 2. Настройте публичный HTTPS (для webhook)

**Вариант A: ngrok (для теста)**
```bash
ngrok http 8000
```

Скопируйте HTTPS URL и зарегистрируйте в MAX:
```
https://ваш-url.ngrok.io/webhooks/max
```

**Вариант B: Реальный сервер**
```
https://ваш-домен.ru/webhooks/max
```

### 3. Тест round-trip

Напишите боту в MAX:
```
Какой рабочий график?
```

Должен прийти ответ со ссылкой на документ.

## 🎬 Сценарий демонстрации жюри

### 1. Показать чат сотрудника (5 мин)

Откройте `/demo/max/chat`:

1. Регистрация: `/start` → заполните 4 вопроса
2. Вопрос из базы: `Какой рабочий график?` → показать источник
3. Вопрос вне базы: `Где получить пропуск?` → эскалация в HR

### 2. HR-дашборд (3 мин)

Главная страница → роль "HR-менеджер":
- Открытые обращения
- Агрегированные темы
- Статистика

### 3. Руководитель (2 мин)

Роль "Руководитель подразделения":
- Этапы адаптации команды
- **БЕЗ личной переписки**

### 4. Топ-менеджмент (2 мин)

Роль "Руководитель по подбору":
- Weekly digest
- Зоны внимания
- **БЕЗ персональных данных**

## 🔐 Безопасность и приватность

- ✅ **RAG проверяет источник** перед ответом
- ✅ **GigaChat вызывается** только при наличии релевантного документа
- ✅ **Эскалация требует подтверждения** сотрудника
- ✅ **HR видит только** подтверждённые обращения
- ✅ **Руководители не видят** содержание переписки
- ✅ **Агрегация без персональных данных** для топ-менеджмента
