# Быстрый старт

## Запуск на Windows

Нужен Python 3.10 или новее. В корне проекта выполните:

```bat
start_demo.bat
```

Скрипт создаст виртуальное окружение, скопирует `.env.example` в `.env`, установит зависимости и запустит сервер. В демонстрационном режиме ключи GigaChat и MAX не нужны.

После запуска откройте:

| Страница | Адрес |
| --- | --- |
| Основной стенд | http://127.0.0.1:8000 |
| Демо-чат MAX | http://127.0.0.1:8000/demo/max/chat |
| Документация API | http://127.0.0.1:8000/docs |
| Состояние сервиса | http://127.0.0.1:8000/api/health |

Для остановки нажмите `Ctrl+C` в окне сервера.

## Ручной запуск

```powershell
Copy-Item .env.example .env
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
cd backend
uvicorn app.main:app --reload
```

## Что показать в демо

1. Введите `/start` и пройдите короткую регистрацию: должность, опыт, площадка и дата первого рабочего дня.
2. Спросите «Какой рабочий график?» — бот ответит по локальной базе знаний и укажет источник.
3. Задайте вопрос, на который нет ответа в базе. Бот предложит подготовить обращение HR и отправит его только после команды «Отправить HR».
4. Откройте ролевые API на основном стенде или напрямую:
   - HR: http://127.0.0.1:8000/api/dashboard/hr
   - Руководитель: http://127.0.0.1:8000/api/dashboard/manager
   - Руководитель управления: http://127.0.0.1:8000/api/dashboard/director

## Проверка проекта

Из корня репозитория:

```powershell
.\.venv\Scripts\python.exe -m compileall -q backend
$env:PYTHONPATH = "backend"
.\.venv\Scripts\python.exe -m pytest -q backend/tests
node --check backend/app/static/app.js
```

## Если что-то не работает

- **Порт 8000 занят:** из папки `backend` выполните `..\.venv\Scripts\python.exe -m uvicorn app.main:app --port 8001` и откройте `http://127.0.0.1:8001`.
- **Зависимости не установились:** выполните `.\.venv\Scripts\python.exe -m pip install -r requirements.txt` из корня проекта.
- **База знаний пустая:** проверьте наличие Markdown-файлов в `backend/data/knowledge_base` и перезапустите сервер. Локальная SQLite-база создаётся автоматически.
- **Нужен реальный GigaChat или MAX:** следуйте разделам основного [README.md](./README.md); демонстрационный режим для этого менять не требуется, пока внешние интеграции не настроены.
